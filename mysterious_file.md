# Документация `mysterious_file.py`

Этот документ описывает назначение функций файла `mysterious_file.py`, их параметры, возвращаемые значения и примеры вызова.

## `make_tea`

Готовит строковое описание чая из заданного объёма воды и количества ложек сахара.

### Аргументы

- `water_ml` (`int`): объём воды в миллилитрах.
- `sugar_spoons` (`int`): количество ложек сахара.

### Возвращает

`str`: описание приготовленного напитка.

### Пример

```python
make_tea(200, 2)
# 'Чай: 200 мл воды, 2 ложки сахара'
```

## `buy_products`

Вычисляет сдачу после покупки нескольких одинаковых товаров. Если денег недостаточно, сообщает об этом строкой.

### Аргументы

- `money` (`int | float`): сумма денег у покупателя.
- `price_per_item` (`int | float`): цена одного товара.
- `items_count` (`int`): число покупаемых товаров.

### Возвращает

`int | float | str`: сдачу либо строку `"Недостаточно денег"`.

### Пример

```python
buy_products(100, 10, 5)
# 50

buy_products(100, 10, 11)
# 'Недостаточно денег'
```

## `is_weekend`

Определяет, является ли переданный день недели выходным.

### Аргументы

- `day` (`str`): название или сокращённое название дня недели.

### Возвращает

`bool`: `True`, если указан субботний или воскресный день; иначе `False`.

### Пример

```python
is_weekend("Суббота")
# True

is_weekend("Пятница")
# False
```

## `is_even`

Проверяет, делится ли целое число на два без остатка.

### Аргументы

- `number` (`int`): проверяемое число.

### Возвращает

`bool`: `True` для чётного числа, иначе `False`.

### Пример

```python
is_even(6)
# True

is_even(7)
# False
```

## `find_multiples_of_three`

Формирует список чисел из заданного диапазона, которые делятся на три без остатка.

### Аргументы

- `start` (`int`): начало диапазона, включается в проверку.
- `stop` (`int`): граница диапазона, не включается в проверку.
- `step` (`int`, по умолчанию `1`): шаг перебора значений.

### Возвращает

`list[int]`: список чисел, кратных трём.

### Пример

```python
find_multiples_of_three(1, 10)
# [3, 6, 9]

find_multiples_of_three(3, 15, 3)
# [3, 6, 9, 12]
```

## `sentiment_score`

Рассчитывает оценку эмоциональной окраски текста по спискам положительных и отрицательных слов. Положительное слово увеличивает оценку на один, отрицательное — уменьшает на один. Знак `!` в конце слова умножает текущую оценку на `1.5`, а знак `?` — на `0.3`.

### Аргументы

- `text` (`str`): текст для анализа.
- `positive_words` (`list[str]`): список положительных слов.
- `negative_words` (`list[str]`): список отрицательных слов.

### Возвращает

`float`: итоговая оценка, округлённая до одного знака после запятой.

### Пример

```python
sentiment_score("I love Python!", ["love"], ["hate"])
# 1.5

sentiment_score("Do I hate Python?", ["love"], ["hate"])
# -0.3
```

## `to_binary_string`

Преобразует целое неотрицательное число в строковое двоичное представление.

### Аргументы

- `number` (`int`): исходное число.
- `iteration_count` (`int`, по умолчанию `0`): счётчик итераций преобразования.

### Возвращает

`str`: двоичная строка.

### Пример

```python
to_binary_string(10)
# '1010'

to_binary_string(0)
# '0'
```
